# LocalVault

Bitwardenの通常JSONエクスポートを取り込み、PC内だけで使う軽量なWindows向けパスワード保管庫です。
サーバー、Docker、同期機能はありません。

## MVPでできること

- Bitwarden通常JSONのインポート
- Login / Secure Note / Card / Identity / SSH Keyの取り込み
- フォルダ、URI、TOTP、カスタムフィールドの取り込み（フォルダとTOTPは保持のみで、画面には表示しない。TOTPコードの生成には非対応）
- URIを1件1行のグリッドで編集し、http/https URIを既定ブラウザで開く
- カスタムフィールドは Name / Value / Type のグリッドで編集（Bitwarden type=0 は通常表示、type=1 は既定でマスクし明示操作で表示）
- 未対応のBitwarden項目を元JSONとして暗号化Vault内に保持
- Vault一覧（名前・ユーザー名・種類）、検索（名前・ユーザー名・URI）
- 新規、編集、削除
- ユーザー名・パスワードのClipboardコピー（一覧・アイテム編集画面）
- ポリシー指定によるパスワード生成、生成結果の手動編集、更新成功後の確定
- 新規アイテム作成時にも同じ生成ポリシーでパスワードを生成可能
- 旧パスワードおよびType=1（非表示）追加項目の変更履歴を保持・閲覧・コピー（アイテムごとに最大10件）
- Clipboard自動消去（既定ON、既定30秒。全体設定でON/OFF・秒数を変更可能）
- 無操作時の自動ロック（既定5分。全体設定で変更可能）
- Vault全体をArgon2id + AES-256-GCMで暗号化
- Vault保存成功後にOneDrive等の指定フォルダへ暗号化済み世代バックアップ
- 外部バックアップの保持世代数を設定可能（初期値30）

## 保存形式

保存先:

```text
%LOCALAPPDATA%\LocalVault\vault.lvault
```

`vault.lvault` 自体はJSON形式のEnvelopeですが、保管データは暗号文です。

```text
Master Password
    ↓
Argon2id
  - memory: 64 MiB
  - iterations: 3
  - parallelism: 2
    ↓
256-bit key
    ↓
AES-256-GCM
  - nonce: 12 bytes / 保存ごとにランダム生成
  - tag: 16 bytes
    ↓
vault.lvault
```

Vault本体の更新は一時ファイルから置換します。同一PC内の `vault.lvault.bak` は作りません。

## OneDriveバックアップ

`全体設定` の `バックアップ設定` から、OneDrive内のバックアップ先フォルダと保持世代数を指定します。
Windowsの `OneDrive` / `OneDriveConsumer` / `OneDriveCommercial` 環境変数が見つかる場合は、フォルダ選択画面の初期位置として使用します。

バックアップは一定時間ごとの無条件コピーではなく、**Vaultの内容が変更され、本体保存に成功した直後**に作成します。変更がない間は同一内容のバックアップを増やしません。

```text
%LOCALAPPDATA%\LocalVault\vault.lvault
    ↓ 保存完了（ファイルは閉じた状態）
OneDrive\LocalVaultBackup\
    ├─ vault-20260827-064500-1234567.lvault
    ├─ vault-20260827-071203-4567890.lvault
    └─ ...
```

- バックアップ対象は暗号化済み `vault.lvault` そのものです。平文Vaultは生成しません。
- バックアップ失敗時も、ローカルVault本体の保存成功は取り消しません。画面に警告します。
- 設定確定時には、その場で現在のVaultを1回バックアップし、保存先が利用可能か確認します。
- 保持世代数を超えた `vault-*.lvault` は古いものから削除します。
- アプリ設定は `%LOCALAPPDATA%\LocalVault\settings.json` に保存します。バックアップ先パス・世代数・パスワード生成ポリシー（生成・更新画面で「既定として保存」した場合のみ）を保存しますが、Vault内容・生成したパスワード・マスターパスワードは保存しません。

## ビルド

Windows + .NET 8 SDK:

```powershell
dotnet restore
dotnet build -c Release
dotnet run
```

単一EXEに近い形で発行する場合:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

## Bitwardenからの移行

1. LocalVaultを初回起動する。
2. LocalVault用マスターパスワードを設定する。
3. `全体設定` を開き、`Bitwarden JSON取込` を押す。
4. Bitwardenからエクスポート済みの通常 `.json` を選択する。
5. 件数を確認する。
6. LocalVaultでログイン情報が利用できることを確認する。
7. 平文のBitwarden JSONを安全に削除する。

再インポートはできません。取り込み済みのBitwarden item `id` はスキップし、まだ取り込んでいないアイテムだけを追加します。LocalVaultでのパスワード更新や履歴は上書きされません。

## パスワード更新

既存アイテムのパスワードは、編集画面で直接書き換えられません。編集画面の `パスワード更新` から、次の順序で更新します。Type=1（非表示）の追加項目も、行の `更新` ボタンから同じ画面で更新します。

1. 更新画面の入力欄には現在の値が入っている。直接編集するか、ポリシー（長さ・文字種・最低数字数・最低記号数）を指定して `生成` する。
2. コピーして更新先サービスへ貼り付ける。
3. 更新先で新しいパスワードによる更新成功を確認する。
4. `更新成功・確定` を押す。新しい値が編集画面に反映される（この時点ではVault未保存）。
5. 編集画面で `保存` を押す。旧値を履歴へ移し、新しい値を現在値としてVaultへ保存する。

- 生成ポリシーは「生成時の条件」であり、手動編集した値には適用しません。
- 最低数字数・最低記号数は指定どおりに保証します（0なら保証しない）。英大文字・英小文字は選択時に最低1文字を含みます。
- ポリシーは、更新・生成画面で `このポリシーを既定として保存する` を選んだ場合だけ既定値として保存します。
- 現在と同じ値は確定できません。
- 未確定の値がある状態で更新画面を閉じようとすると確認します。
- 更新を確定した後、編集画面を保存せずに閉じようとすると「パスワードが保存されていない」と警告します。新規作成でパスワードや非表示項目の値を入力した後に閉じようとした場合も警告します。
- 既存のType=1（非表示）追加項目の行を削除した場合も、保存時に旧値を履歴へ残します。
- 保存に失敗した場合は、アイテムを保存前の状態に戻し、編集画面を開いたままにします。再度 `保存` できます。

`パスワード履歴` はVaultデータとして保持され、アイテム編集画面の `変更履歴` から確認・コピーできます。

- 本体パスワードは `ユーザー名: 値`、Type=1（非表示）の追加項目は `項目名: 値` の形式で、1つの履歴にまとめて表示します。
- ユーザー名は履歴を記録した時点の値です。記録のない既存・インポート分は、現在のユーザー名で表示します。
- 編集画面で更新を確定したが未保存の旧値は、`未保存（保存時に記録）` として先頭に表示します。
- 値は既定でマスクします。`すべて表示` か右クリックメニューで、行ごとに表示できます。ダブルクリックでコピーします。
- 履歴はアイテムごとに最大10件です。超えた分は古いものから削除します。
- Bitwarden JSONに含まれている `passwordHistory` もインポートします（最大10件）。

## セキュリティ上の境界

- 独自暗号アルゴリズムは実装していません。
- KDFは `Konscious.Security.Cryptography.Argon2` のArgon2idを使用します。
- 暗号化は.NET標準 `System.Security.Cryptography.AesGcm` を使用します。
- マスターパスワードそのものは保存しません。
- 復号鍵はロックまでメモリ上に保持し、破棄時に `CryptographicOperations.ZeroMemory` で消去します。
- 復号済みVaultを一時ファイルへ保存しません。
- Bitwarden通常JSONは平文なので、インポート後もLocalVaultから自動削除しません。誤削除防止のためです。
- OneDriveへ送られるのはAES-256-GCM暗号化済みのVaultファイルだけです。
- OneDrive APIやMicrosoftアカウント認証はアプリに持たせず、WindowsのOneDrive同期クライアントに同期を委ねます。

### 現時点の制約

.NET/WinFormsの `string` はimmutableなmanaged objectなので、画面入力済みパスワードや復号後の文字列について「RAMから確実にゼロ化した」と保証はできません。
また、ブラウザ拡張、自動入力、クラウド同期、組織共有、添付ファイル、Passkeyとしての認証処理、SSH Agent機能は実装していません。

Bitwardenの元アイテムJSONは暗号化Vault内に保持するため、未対応データをインポート時に破棄しません。

`Assets/LocalVault.ico` をEXEと各WinForms画面のアイコンとして使用します。


## 全体設定

ツールバーの `全体設定` から以下を変更できます。

- ロックまでの時間（分）: 既定5分
- Clipboard自動消去: 既定ON
- Clipboard消去までの時間（秒）: 既定30秒

Clipboard自動消去をOFFにした場合、LocalVaultがコピーした内容を時間経過やロック時に自動消去しません。

全体設定の `データ` 欄から、`Bitwarden JSON取込` と `バックアップ設定` も開けます。これらは全体設定のOK/キャンセルとは独立して、その場で反映・保存されます。

ロックは無操作時の自動ロックで行います。手動でロックするボタンはありません。アイテムの新規作成・編集画面を開いている間は自動ロックを止め、画面を閉じた時点から無操作時間の測定を再開します（更新先サイトでの作業中にロックされて、未保存のパスワードが失われるのを防ぐため）。
